# ETL-пайплайн
Сервис для извлечения данных из документов с целью их дальнейшей обработки, например, в RAG

## Описание
ETL-пайплайн поддерживает обработку текстовых и графических документов. Результатом обработки является json-структурированная информация, которая в дальнейнем может быть использована другими сервисами

## Запуск через Docker
docker build --no-cache -t etl-test .  
docker run -d -it -p 9999:8999 --name dt etl-test

## Использование
1. Откройте в браузере http://localhost:9999/
2. Выберете файл для обработки
3. Нажмите кнопку "Отправить"
4. В результате получите json-структурированную информацию

## Используемые инструменты
- Docling
- FastAPI
